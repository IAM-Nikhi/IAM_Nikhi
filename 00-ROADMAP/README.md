# IAM_Nikhi Learning & Project Roadmap

## Phase 1: Core Identity Foundations
Topics: identity lifecycle, authoritative sources, correlation, accounts, entitlements, least privilege, RBAC, JML.

Deliverables:
- enterprise architecture
- identity attribute dictionary
- JML workflow
- birthright role model
- termination control matrix

## Phase 2: Directory Services
Topics: Active Directory, Microsoft Entra ID, LDAP, users, groups, OUs, nested groups, privileged groups, stale accounts, reconciliation.

## Phase 3: IGA Platforms
### SailPoint
Aggregation, identity refresh, access requests, provisioning, certifications, roles, entitlement governance, troubleshooting.

### RSA IGL
Collectors, access visibility, account/access review, entitlement governance, orphan access, remediation.

### Saviynt
Connections, account and entitlement imports, analytics, request governance, campaigns, provisioning, application onboarding.

## Phase 4: Federation & SSO
SAML 2.0, OAuth 2.0, OIDC, IdP/SP roles, claims, tokens, authorization code flow, SSO troubleshooting.

## Phase 5: ITSM & Monitoring
ServiceNow request/incident/change/remediation workflows and Splunk monitoring for IAM events.

## Phase 6: Data & Integration
SQL/MySQL, REST APIs, JSON, CSV/flat files, delta/full loads, reconciliation, correlation and error handling.

## Phase 7: Governance & Compliance
SOX ITGC, ISO 27001, NIST, least privilege, RBAC, SoD, access certification and privileged access governance.

## Phase 8: Interview Portfolio
Explain every lab using: business problem, identity risk, architecture, workflow, troubleshooting, evidence and result.
