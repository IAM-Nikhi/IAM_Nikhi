# Lab 05 - Saviynt Application Onboarding

## Scenario
Onboard fictional application **VendorPay**.

Accounts:
- username
- employeeId
- status
- email

Entitlements:
- VendorPay-Viewer
- VendorPay-Creator
- VendorPay-Approver
- VendorPay-Admin

## Governance
- Viewer: manager approval
- Creator: manager approval
- Approver: manager + app owner
- Admin: manager + app owner + security
- Creator + Approver: SoD conflict

## Tasks
1. define account correlation,
2. define entitlement ownership,
3. define requestability,
4. design approval workflow,
5. define certification frequency,
6. define termination behavior,
7. write test cases,
8. identify privileged access.
