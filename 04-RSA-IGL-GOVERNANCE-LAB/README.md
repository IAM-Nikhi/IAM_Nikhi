# Lab 04 - RSA Identity Governance & Lifecycle

## Focus
Collectors, account/access visibility, entitlement governance, access reviews, orphan accounts, review campaigns and remediation.

## Exercise
Use `data/rsa_review_population.csv`.

Tasks:
1. identify access owned by terminated identities,
2. identify orphan accounts,
3. flag privileged entitlements,
4. determine reviewer,
5. recommend remediation.

Allowed decisions:
- Approve
- Revoke
- Investigate
- Exception
