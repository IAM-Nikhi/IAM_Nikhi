# Lab 03 - SailPoint Operations

## Scenario 1: Approved request but no access
Investigate request status, approvals, SoD checks, provisioning plan, connector response, target account, entitlement native value and aggregation.

## Scenario 2: Certification shows stale access
Investigate last aggregation, account correlation, entitlement refresh, disabled/duplicate accounts and target-system changes.

## Scenario 3: Mover retains old access
Investigate identity attributes, role membership, refresh task, lifecycle trigger, deprovisioning policy and manually granted access.

## Practical Exercise
Use `data/sailpoint_identity_snapshot.csv`. Determine what should be removed after Nina moves to Treasury.
