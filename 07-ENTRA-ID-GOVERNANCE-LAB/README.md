# Lab 07 - Microsoft Entra ID Governance

## Topics
Users, groups, RBAC, access reviews, Conditional Access, MFA, PIM concepts, stale guests and privileged role reviews.

## Tasks
1. Export group membership.
2. Review directory role assignments.
3. Identify stale guest accounts.
4. Design a Conditional Access policy.
5. Explain emergency-access exclusions.
6. Review privileged roles.
7. Simulate an access-review decision.

## Example Conditional Access intent
- require MFA for admins,
- require MFA for external users,
- block legacy authentication,
- require compliant devices for sensitive apps,
- use report-only mode before enforcement.
